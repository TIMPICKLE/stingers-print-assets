# STINGERS 印花矢量源文件

本仓库保存依据原设计图逐个裁切、逐个描摹的 STINGERS 印花生产文件。V2 版本保留了原图中两种不同长度的 S 元素，并按原稿分别处理其他图形，没有用统一重绘的替代造型。

## 目录

- `01_original_crops/`：从原设计图逐项裁下的原始对照图
- `02_vector_individual/`：每个元素独立的 SVG、PDF、EPS 矢量文件
- `03_transparent_png_300dpi/`：每个元素独立的 300 dpi 透明背景 PNG
- `STINGERS_original_layout_vector.*`：整张原版排版的 SVG、PDF、EPS
- `COMPARE_*.jpg`：原图与矢量稿的对照检查图
- `README_逐元素说明.txt`：逐元素编号与生产说明

## 交付厂商建议

优先提供 PDF 或 EPS；厂商支持 SVG 时也可直接使用。PNG 用于预览、DTF/DTG 或不接受矢量文件的生产流程。正式生产前，应让厂商按实际印刷工艺确认专色、尺寸、出血和最小线宽，并先做样衣。

所有文字和数字已转为路径，PDF 内不含嵌入位图或活动字体。
