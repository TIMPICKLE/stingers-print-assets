STINGERS 原图逐元素矢量描摹 V2
================================

本版本不重新设计任何元素。16 个可见对象分别从用户提供的 1054x1492 原图中独立抠出，
再按紫色和金色色块边界转换为封闭矢量路径。重复出现的短版 S 也分别保留，没有强行替换成
同一个正常长版 S。

颜色统一依据上传源 PDF：
- 紫色 #461D7D
- 金色 #FED023
- S 头部由源 PDF 确认存在的白色小高光已单独保留

目录：
- 01_original_crops：逐个抠出的原始图像，用于核对造型
- 02_vector_individual：每个元素独立的 SVG / PDF / EPS 真矢量文件
- 03_transparent_png_300dpi：同一矢量文件导出的透明底 300 DPI PNG
- STINGERS_original_layout_vector.svg：保持原排版、每个对象独立分组的可编辑总源文件
- STINGERS_original_layout_vector.pdf：文字也已变为轮廓路径的生产 PDF
- COMPARE_original_left_vector_right.jpg：左侧原图、右侧矢量重建的逐项对照
- COMPARE_elements_original_vs_vector.jpg：16 个元素逐一的原图/矢量对照

说明：
- 矢量路径是对原 JPEG 可见轮廓的忠实描摹，不是对原设计进行猜测或二次创作。
- 原图中的柔化/抗锯齿像素已去除，输出采用硬边界与源 PDF 的标准纯色。
- 圆章保留白色底面；其他区域默认透明。
- 当前总版按 A3 宽 297mm 建立。独立文件可无损缩放，正式生产仍需确定每个印花的最终毫米尺寸。

抠图覆盖率：100.0000%（原图中识别到的紫/金有效像素均已落入独立元素区域）
